# SRLearnX - Online Learning Platform

SRLearnX is a comprehensive online learning platform built with Angular, designed to provide high-quality educational courses and services.

This project was generated using [Angular CLI](https://github.com/angular/angular-cli) version 19.2.12.

## Development server

To start a local development server, run:

```bash
ng serve
```

Once the server is running, open your browser and navigate to `http://localhost:4200/`. The application will automatically reload whenever you modify any of the source files.

## Code scaffolding

Angular CLI includes powerful code scaffolding tools. To generate a new component, run:

```bash
ng generate component component-name
```

For a complete list of available schematics (such as `components`, `directives`, or `pipes`), run:

```bash
ng generate --help
```

## Building

To build the project run:

```bash
ng build
```

This will compile your project and store the build artifacts in the `dist/` directory. By default, the production build optimizes your application for performance and speed.

## Running unit tests

To execute unit tests with the [Karma](https://karma-runner.github.io) test runner, use the following command:

```bash
ng test
```

## Running end-to-end tests

For end-to-end (e2e) testing, run:

```bash
ng e2e
```

Angular CLI does not come with an end-to-end testing framework by default. You can choose one that suits your needs.

## Features

- **Course Catalog**: Browse and purchase from a variety of professional courses
- **User Authentication**: Secure login and signup with OTP verification
- **School Fee Payment**: Convenient online payment system for school fees
- **Responsive Design**: Optimized for all devices from mobile to desktop
- **Shopping Cart**: Add courses to cart and proceed to checkout
- **Golden & Red Theme**: Premium look and feel with a distinctive color scheme

## Pages

- **Home**: Featured courses, stats, and learning path
- **Courses**: Complete course catalog with filtering options
- **Login/Signup**: User authentication with OTP verification
- **School Fees**: Payment portal for school fees
- **About Us**: Information about SRLearnX
- **Contact**: Get in touch with the SRLearnX team
- **Career**: Career opportunities at SRLearnX
- **Blog**: Educational articles and updates
- **Policies**: Refund policy, terms & conditions, and privacy policy
